# ofir-landing

Landing page variants for Ofir Israel, CPA — three color treatments of the same single-file design.

- `ofir_v5_petrol.html` — petrol + amber on warm stone
- `ofir_v5_emerald.html` — emerald + gold on ivory
- `ofir_v5_azure.html` — cobalt + cyan on white

Each file is self-contained (HTML + inline CSS/JS). Bilingual HE/EN, RTL-first.
